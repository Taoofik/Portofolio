Projet Bibliothèque

Une application de gestion de bibliothèque : cataloguer des livres, enregistrer les adhérents et suivre les emprunts. Cette page explique comment le projet a été mené, de l’idée jusqu’à la mise en ligne, et comment GitHub m’a servi à l’organiser.

Les objectifs du projet

  • Ajouter, modifier et supprimer des livres du catalogue.
  • Gérer les adhérents de la bibliothèque.
  • Enregistrer les emprunts et les retours, avec les dates associées.
  • Rechercher un livre par titre, auteur ou disponibilité.

Les étapes de réalisation

  1. Analyse du besoin

    Je définis ce que l’application doit faire et qui va l’utiliser. Le résultat est un cahier des charges listant les fonctionnalités attendues.

  2. Conception

    Je dessine la structure des données (livres, adhérents, emprunts) et les liens entre elles, puis les maquettes des écrans principaux.

  3. Développement

    Je code les fonctionnalités l’une après l’autre, en commençant par le catalogue, puis les adhérents, puis les emprunts.

  4. Tests

    Je vérifie chaque fonctionnalité avec des cas normaux et des cas limites, par exemple emprunter un livre déjà prêté.

  5. Documentation et publication

    Je rédige un fichier README qui explique comment installer et utiliser le projet, puis je publie le code sur GitHub.

L’utilisation de GitHub

Git enregistre l’historique de mon code et GitHub l’héberge en ligne. Cela me permet de revenir à une version précédente en cas d’erreur, de travailler sur une nouvelle fonctionnalité sans casser le reste, et de partager le projet facilement.

Dépôt (repository)
Le dossier du projet sur GitHub. Il contient le code, le README et tout l’historique des modifications.
Commit
Un point de sauvegarde avec un message qui décrit ce qui a changé.
Branche
Une copie parallèle du projet pour développer une fonctionnalité sans toucher à la version stable.
Pull request
Une demande pour fusionner une branche dans la branche principale, après relecture.
Issue
Une tâche ou un bug à traiter, qui permet de suivre l’avancement du projet.

Mon déroulé de travail

# 1. Récupérer le projet
git clone https://github.com/votre-pseudo/bibliotheque.git

# 2. Créer une branche pour une fonctionnalité
git checkout -b ajout-emprunts

# 3. Enregistrer mes modifications
git add .
git commit -m "Ajout de l'enregistrement des emprunts"

# 4. Envoyer la branche sur GitHub
git push origin ajout-emprunts

Sur GitHub, j’ouvre ensuite une pull request pour fusionner ajout-emprunts dans la branche main, puis je supprime la branche devenue inutile.

Ce que j’ai appris

  • Découper un projet en petites étapes et les suivre avec des issues.
  • Écrire des messages de commit clairs, pour retrouver facilement une modification.
  • Utiliser les branches pour tester sans risque.
  • Documenter mon travail pour qu’une autre personne puisse le reprendre.
